# Лабораторна робота №8 — сесії, автентифікація, авторизація (Flask)

Файли: `auth.py` (сесії в пам'яті, вхід/вихід, CSRF, `login_required`), `templates/`, `create_users.py`,
`seed_demo_db.py` + `demo_app.py` (тестовий застосунок), `run_experiments.py` (10 експериментів).

Запуск тестового застосунку:
    pip install flask
    python seed_demo_db.py
    python demo_app.py          # http://127.0.0.1:5000, логін admin / ChangeMe#3
Експерименти:  python run_experiments.py
